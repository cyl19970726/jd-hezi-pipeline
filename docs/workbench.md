# 本地工作台

## 启动

```sh
npm run workbench
# http://127.0.0.1:4317
```

工作台需要已建立的私有状态目录和可用的浏览器绑定。生产使用时建议明确设置：

```sh
HEZI_DIR=/absolute/private/state HEZI_PORT=4317 npm run workbench
```

## 显示内容

- 任务及其京东来源、目标店铺和销售规格。
- 当前阶段、耗时、失败原因和缺失项。
- 京东基准价、同规格竞品价和最终上架价。
- 授权、查重、媒体和表单预检结果。
- 草稿、待审核、已驳回与在售等真实远端状态。
- 未知写入和对账状态。

待审核与在售分开显示；未核价不显示成 0 元。

## 安全边界

- 服务只监听 `127.0.0.1`。
- 校验 Host、Origin 和本机会话令牌。
- Cookie 留在 Ego 浏览器会话，不进入 Web 页面。
- 页面每 2.5 秒只读本地状态，不自动刷新两站。
- 启动写入或继续恢复前仍检查状态机、锁和当前版本。
- 不通过调整数据库终态来解除阻塞。

## 恢复

工作台重启后从 SQLite 恢复队列。存在 pending 或 `UNKNOWN_OUTCOME` 时，恢复程序先对账，不自动重试外部写入。浏览器控制权在用户手中时，程序停止争抢。

## 公开版限制

公开仓库不包含任何真实店铺配置、本地数据库或运营报告。首次运行前必须按 [快速开始](quickstart.md) 绑定自己的环境。
